# SmartVerse App

SmartVerse is a student productivity mobile application built using React Native and Firebase.

## Features

- Firebase Authentication
- Notes Management
- CGPA Calculator
- Internship Tracker
- Projects Section
- Profile Management

## Tech Stack

- React Native
- Expo
- Firebase
- TypeScript
